# Mecmua releases

Installers, update files and extension packages for [Mecmua](https://mecmua.netlify.app), a local-first workspace for notes, reading and study.

**Download Mecmua from the website: <https://mecmua.netlify.app/download/>**

This repository holds files only: the app downloads its updates from here, and the extension Marketplace its packages. Paid extension packages are signed and run only with a licence key from the store.
